# Yataktan Kalkma Motivasyon Jeneratörü

## Resmi Açıklama

Bu depo, insanlık tarihinin en büyük mücadelelerinden birini çözmek amacıyla geliştirilmiştir: **sabahları yataktan kalkmak**.

Bilimsel araştırmalar (kendi kendimize yaptığımız) göstermektedir ki, yatak ile insan arasındaki bağ, yerçekimi kuvvetinden daha güçlüdür. Bu nedenle klasik "alarm çalıyor kalk" yöntemi yetersiz kalmaktadır.

Bu sistem, her çalıştırıldığında giderek daha absürt, daha bilimsel görünen ve daha ikna edici motivasyonlar üretir. Bazıları o kadar inandırıcıdır ki, kullanıcı kalkmak zorunda kalır. Bazıları ise "tamam kalkmıyorum" dedirtir. Her iki sonuç da kabul edilebilir.

## Kurulum

```bash
git clone https://github.com/Tentivory/yataktan-kalkma-motivasyon-jeneratoru.git
cd yataktan-kalkma-motivasyon-jeneratoru
python motivasyon.py
```

Python 3 yüklü olması yeterlidir. Ek kütüphane gerekmez. Çünkü bilim böyle çalışır.

## Kullanım

Programı çalıştırdığınızda 3 farklı motivasyon alırsınız. Eğer hiçbiri yetmezse tekrar çalıştırın. Sonsuz döngü önerilmez ama yasak değildir.

## Uyarılar

- Bu program gerçek tıbbi tavsiye değildir.
- Yataktan kalkmak zorunlu değildir.
- Kediler bu programı onaylamamaktadır.
- Evrenin entropisi artmaya devam etmektedir, suçlu biz değiliz.
